# Conditioning board (rev 3.1): 4-channel shield for the NUCLEO-F072RB

KiCad project `conditioning` (schematic generated by `gen_kicad.py`, then edited in KiCad 10).
One MCP6004 conditions the 4 FlexiForce A201 sensors (V_OUT = V_REF x (1 + R_F / R_sensor)); the board plugs on the Arduino headers of the Nucleo.

## Connectors

| Ref | Function | Footprint |
|---|---|---|
| FS1-FS4 | FlexiForce sensors, plugged directly (outer pins active, centre pin unused) | 1x03 female socket, 2.54 mm |
| J1 | Nucleo CN6 (power): 3V3 and GND used | 1x08 male header |
| J2 | Nucleo CN8 (analog): A0-A3 sensors, A4 V_REF | 1x06 male header |
| J3 | Nucleo CN9 (digital): D7/PA8 camera trigger, D6/PB10 camera strobe; D0/D1 (ST-LINK UART) left free | 1x08 male header |
| J4 | Cameras: 1 trigger, 2 strobe, 3 GND | 1x03 male header |
| JP1 | Mode: 1-2 sensitive (1.03 V), 3-4 standard (0.51 V), 5-6 high force (0.10 V) | 2x03 header + jumper |
| JP2 | 3V3 from the Nucleo; remove the jumper to measure the current | 1x02 header + jumper |
| JP3-JP6 | Op-amp output to the RO/CO filter; remove to drive the filter from a generator | 1x02 header + jumper |

## Test points

Single header pins (1x01).

| Ref | Signal |
|---|---|
| TP1-TP4 | op-amp outputs (before RO) |
| TP5-TP8 | ADC inputs (after the RO/CO filter) |
| TP9 | V_REF |
| TP10 | 3V3 |
| TP11-TP14 | GND, one near each channel for the probe clips |

No test point on the inverting inputs: a probe there adds about 100 pF and makes the amplifier ring.

## Shield placement

The male headers are inserted from the component side and soldered on the copper side, so the board works single-sided.
Header positions, from the Arduino Uno R3 layout (pin centres, mm, origin on A0, x to the right, y towards the digital headers):

| Header | Pin 1 | Last pin | y |
|---|---|---|---|
| J2 (CN8) | A0: x = 0 | A5: x = 12.70 | 0 |
| J1 (CN6) | NC: x = -22.86 | VIN: x = -5.08 | 0 |
| J3 (CN9) | D0: x = 15.24 | D7: x = -2.54 | 48.26 |

Check these positions before etching: place the KiCad footprint `Module:Arduino_UNO_R3` on the PCB as a reference, or measure the Nucleo headers.

Height: the Nucleo with the shield fits between the plates of the test rig (47.75 mm gap); orient the corner modules so that the sensor tails point to the centre.

## Etching rules (Polytech machine, provisional)

Single-sided, no plated holes: tracks 0.6 mm minimum, clearance 0.5 mm, pads 2 mm minimum (2.5 mm for headers), 1.0 mm drills for headers, 0.8 mm for resistors and capacitors. To be confirmed with the technician.
